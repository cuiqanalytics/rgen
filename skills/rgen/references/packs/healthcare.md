# Data pack: healthcare (Healthcare 1.0.0)

Generated by rgen-cli/site-packs.sh from the pack; edit lookup_data/packs/healthcare/skill.md in cuiqGEN instead.
Read only when `rgen packs list` shows this pack as licensed.

Use for patients, encounters, diagnoses, prescriptions, lab results and medical claims (US).
Diagnoses are real ICD-10-CM codes (FY2027) that respect each code's age and sex limits, drugs
are real FDA NDC packages matched to the condition, NPIs carry a valid check digit, and lab
values shift with disease. All records are synthetic. CPT codes are not included (AMA license);
use `healthcare_hcpcs` for HCPCS Level II drug, supply and equipment codes.

| Driver column | Dependent providers |

| diagnosis | `healthcare_condition(dx)`, `healthcare_icd_description(dx)` |

| ndc | `healthcare_drug_generic(ndc)`, `healthcare_drug_brand(ndc)`, `healthcare_drug_strength(ndc)`, `healthcare_drug_form(ndc)`, `healthcare_dea_schedule(ndc)` |

Standalone: `healthcare_mrn`, `healthcare_npi` (`healthcare_npi('organization')` for billing
NPIs), `healthcare_hcpcs` (or `healthcare_hcpcs('J')`: J drugs, A supplies, E equipment,
G services, L orthotics), `healthcare_denial_reason`.

claims → prescriptions and lab results that match the encounter's condition), `healthcare/claims`.

## Pitfalls

- Never nest: `healthcare_ndc(healthcare_condition(healthcare_diagnosis(sex, age)))` re-draws
  inside each call. Keep diagnosis and condition as their own columns.
- Child tables (prescriptions, labs) must copy the condition from the encounter with a match
  lookup, and the foreign key must not be named like the parent's key (`encounter_ref`, not
  `encounter_id`; `patient_ref`, not `patient_id`).
- `healthcare_ndc` is NULL for conditions usually managed without a prescription (routine exam,
  pregnancy supervision, sprains, newborn care); filter or keep the NULLs as "no Rx".
- Pass `age` to `healthcare_specialty` or adults may be assigned to Pediatrics.
- `healthcare_lab_value` without a condition gives healthy values; pass the condition to get
  high HbA1c in diabetics, high TSH in hypothyroidism, and so on.
- Amounts are USD and illustrative, not a fee schedule. Paid = allowed − patient
  responsibility is left to a `derived` column (see the templates).

## All providers

Use in `-p` without the `rand_` prefix; in TOML `derived` expressions with it.

- `healthcare_age()`: patient age in years, following the US population pyramid
- `healthcare_allowed(charge,pay)`: allowed amount for a charge under a payer type — dependent: healthcare_allowed(charge, payer)
- `healthcare_birthdate(age)`: birth date for an age in years — dependent: healthcare_birthdate(age)
- `healthcare_charge(pos)`: billed charge (USD) typical of a place of service — dependent: healthcare_charge(pos)
- `healthcare_claim_status(pay)`: claim status: paid, denied or pending; patient billed for self-pay — e.g. healthcare_claim_status(payer)
- `healthcare_condition(dx)`: condition group of a diagnosis code (hypertension, type2_diabetes, ...) — dependent: healthcare_condition(diagnosis)
- `healthcare_condition_label(cond)`: readable condition name — dependent: healthcare_condition_label(condition)
- `healthcare_days_supply(cond)`: days supply: 30 or 90 for chronic conditions, 5-14 for acute ones — dependent: healthcare_days_supply(condition)
- `healthcare_dea_schedule(ndc)`: DEA controlled-substance schedule of an NDC (CII..CV) or NULL — dependent: healthcare_dea_schedule(ndc)
- `healthcare_denial_reason()`: claim denial reason with its CARC code
- `healthcare_diagnosis(sex,age)`: ICD-10-CM diagnosis code valid for the sex (F/M) and age, weighted by outpatient prevalence — dependent: healthcare_diagnosis(sex, age)
- `healthcare_drug_brand(ndc)`: proprietary (brand or labeler) name of an NDC — dependent: healthcare_drug_brand(ndc)
- `healthcare_drug_form(ndc)`: dosage form of an NDC (TABLET, CAPSULE, ...) — dependent: healthcare_drug_form(ndc)
- `healthcare_drug_generic(ndc)`: generic drug name of an NDC — dependent: healthcare_drug_generic(ndc)
- `healthcare_drug_strength(ndc)`: strength of an NDC (e.g. 10 mg) — dependent: healthcare_drug_strength(ndc)
- `healthcare_hcpcs(hkind)`: HCPCS Level II code; kind J (drugs), A (supplies), E (equipment), G (services), L (orthotics) or any
- `healthcare_icd_description(dx)`: official ICD-10-CM description of any code (dotted, e.g. E11.9) — dependent: healthcare_icd_description(diagnosis)
- `healthcare_lab_flag(test,val)`: abnormal flag L, H or N for a value against the reference range — dependent: healthcare_lab_flag(loinc, value)
- `healthcare_lab_name(test)`: name of a lab test — dependent: healthcare_lab_name(loinc)
- `healthcare_lab_range(test)`: reference range of a lab test, low-high — dependent: healthcare_lab_range(loinc)
- `healthcare_lab_test(cond)`: LOINC code of a common lab test; with a condition, tests it affects are likelier — e.g. healthcare_lab_test(condition)
- `healthcare_lab_unit(test)`: unit of a lab test (UCUM) — dependent: healthcare_lab_unit(loinc)
- `healthcare_lab_value(test,cond)`: result value of a lab test, shifted for a condition (HbA1c high in diabetes, TSH high in hypothyroidism, ...) — dependent: healthcare_lab_value(loinc, condition)
- `healthcare_member_id(payer)`: member ID for a payer: Medicare MBI format for Medicare, NULL for self-pay — dependent: healthcare_member_id(payer)
- `healthcare_mrn()`: medical record number, MRN plus 8 digits
- `healthcare_ndc(cond)`: 11-digit NDC package of a real drug used for a condition (NULL if none) — dependent: healthcare_ndc(condition)
- `healthcare_npi(kind)`: 10-digit NPI with valid check digit (Luhn with the 80840 prefix); kind individual or organization
- `healthcare_patient_responsibility(allowed,payer)`: patient share (copay, coinsurance, or all of it for self-pay), never above the allowed amount — dependent: healthcare_patient_responsibility(allowed, payer)
- `healthcare_payer(age)`: insurance type for an age: Medicare at 65+, Medicaid-heavy for children — dependent: healthcare_payer(age)
- `healthcare_pos()`: CMS place-of-service code (11 office, 23 emergency room, ...), realistic mix
- `healthcare_pos_name(pos)`: name of a place-of-service code — dependent: healthcare_pos_name(pos)
- `healthcare_refills(cond)`: refills: several for chronic conditions, none for acute ones — dependent: healthcare_refills(condition)
- `healthcare_specialty(cond,age)`: provider specialty that treats a condition; Pediatrics only under 18 — dependent: healthcare_specialty(condition, age)
