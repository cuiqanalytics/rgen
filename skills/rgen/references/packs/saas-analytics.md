# Data pack: saas-analytics (SaaS & Product Analytics 1.0.0)

Generated by rgen-cli/site-packs.sh from the pack; edit lookup_data/packs/saas-analytics/skill.md in cuiqGEN instead.
Read only when `rgen packs list` shows this pack as licensed.

Use for product-analytics and growth data: event streams, user agents, traffic attribution
(UTM, channels), funnels, subscriptions/MRR and A/B tests. Shares and rates are realistic
illustrative defaults, not measurements of a real product.

## Chains (put each driver in its own column, then pass the column)

| Driver column | Dependent providers |
|---|---|
| `saas_user_agent` | `saas_browser(ua)`, `saas_browser_version(ua)`, `saas_os(ua)`, `saas_device(ua)` |
| `saas_traffic_source` ("source / medium") | `saas_utm_source(t)`, `saas_utm_medium(t)`, `saas_utm_campaign(t)`, `saas_channel(t)`, `saas_referrer(t)` |
| event (`saas_event('b2b_saas'\|'ecommerce'\|'mobile_app')`) | `saas_event_stage(event)`, `saas_event_properties(event)` (JSON) |
| `saas_plan` | `saas_billing_period(plan)`, `saas_seats(plan)`, then `saas_mrr(plan, billing, seats)`, `saas_seat_price(plan, billing)` |

Time: `saas_event_time('2025-01-01', '2025-12-31', growth, profile)`; growth 2.0 = volume ramps
up linearly, 1.0 = flat; profile `'b2b'` (weekday working hours) or `'consumer'` (evenings).
Standalone: `saas_feature`, `saas_industry`, `saas_company_size`, `saas_user_role`,
`saas_platform`, `saas_variant(arms)`, `saas_experiment_name`.

Templates: `saas-analytics/accounts`, `/events`, `/funnel` (stages always in order),
`/subscriptions` (state machine), `/ab-test` (control 10% vs treatment 11.5% conversion: a known
lift to check an analysis against).

## Pitfalls

- `saas_device(saas_user_agent())` parses a different random user agent at each reference; keep
  the user agent as a column.
- `saas_event_time` returns a TIMESTAMP; pass date strings, not other columns' random values.
- Events in a template are independent rows; for per-user sessions or ordered journeys use the
  funnel template or a state machine.

## All providers

Use in `-p` without the `rand_` prefix; in TOML `derived` expressions with it.

- `saas_billing_period(pl)`: billing period monthly or annual (bigger plans bill annually more often), NULL for Free — dependent: saas_billing_period(plan)
- `saas_browser(ua)`: browser parsed from a user agent (Chrome, Safari, Edge, Firefox, Samsung Internet) — dependent: saas_browser(user_agent)
- `saas_browser_version(ua)`: major browser version parsed from a user agent — dependent: saas_browser_version(user_agent)
- `saas_channel(tsrc)`: marketing channel grouping (Organic Search, Paid Social, Email, AI Assistants, ...) — dependent: saas_channel(traffic_source)
- `saas_company_size()`: employee-count band (1-10 ... 5000+), SMB-heavy mix
- `saas_device(ua)`: device type (desktop, mobile, tablet) parsed from a user agent — dependent: saas_device(user_agent)
- `saas_event(ptype)`: event name weighted by frequency for a product type: b2b_saas (default), ecommerce or mobile_app
- `saas_event_properties(ev)`: JSON event properties that fit the event (path for page_viewed, revenue for order_completed, ...) — dependent: saas_event_properties(event)
- `saas_event_stage(ev)`: lifecycle stage of an event (acquisition, activation, engagement, revenue, retention, referral) — dependent: saas_event_stage(event)
- `saas_event_time(start_date,end_date,growth,profile)`: timestamp between two dates with growing volume (growth 2 = linear ramp, 1 = flat), weekday and hour-of-day shape (profile b2b or consumer), e.g. saas_event_time('2025-01-01', '2025-12-31')
- `saas_experiment_name()`: experiment key such as pricing_page_v2_202605
- `saas_feature()`: product feature name (SSO, Webhooks, Automations, AI assistant, ...)
- `saas_industry()`: customer industry for B2B accounts
- `saas_mrr(pl,billing,seats)`: monthly recurring revenue = seat price x seats — dependent: saas_mrr(plan, billing_period, seats)
- `saas_os(ua)`: operating system parsed from a user agent — dependent: saas_os(user_agent)
- `saas_plan()`: subscription plan (Free, Starter, Pro, Business, Enterprise), freemium-shaped mix
- `saas_platform()`: client platform web, ios or android
- `saas_referrer(tsrc)`: referrer URL of a traffic source, NULL for direct and email — dependent: saas_referrer(traffic_source)
- `saas_seat_price(pl,billing)`: list price per seat per month for a plan and billing period (annual is discounted) — dependent: saas_seat_price(plan, billing_period)
- `saas_seats(pl)`: number of seats within the plan's range — dependent: saas_seats(plan)
- `saas_traffic_source()`: traffic source as "source / medium" (google / organic, (direct) / (none), ...), realistic mix
- `saas_user_agent()`: realistic browser user agent, weighted by device/OS/browser share
- `saas_user_role()`: workspace role (owner, admin, member, guest)
- `saas_utm_campaign(tsrc)`: utm_campaign for paid, email and video traffic (q3_webinar, spring_retargeting), NULL otherwise — dependent: saas_utm_campaign(traffic_source)
- `saas_utm_medium(tsrc)`: utm_medium of a traffic source — dependent: saas_utm_medium(traffic_source)
- `saas_utm_source(tsrc)`: utm_source of a traffic source — dependent: saas_utm_source(traffic_source)
- `saas_variant(arms)`: A/B test arm: control or treatment (arms := 3 or 4 adds variant_b, variant_c), equal split

## Templates

Print one with `rgen templates <pack>/<name> > file.toml`, edit, then `rgen run --config file.toml out.duckdb`.

- `saas-analytics/ab-test`: A/B test assignment and outcomes with a built-in 15% relative lift in conversion for treatment
- `saas-analytics/accounts`: B2B accounts with industry, size, plan, billing, seats and MRR, plus their users with roles
- `saas-analytics/events`: Product event stream (b2b_saas taxonomy): users, growth-shaped timestamps, JSON properties, UTM attribution and parsed user agent
- `saas-analytics/funnel`: Visitor-to-paid funnel: traffic source, device and monotonic stage flags/timestamps with channel-dependent conversion
- `saas-analytics/subscriptions`: Subscription lifecycle event log: trial, active, past_due, churned, reactivated
