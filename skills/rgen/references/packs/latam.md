# Data pack: latam (Latin America 1.0.0)

Generated by rgen-cli/site-packs.sh from the pack; edit lookup_data/packs/latam/skill.md in cuiqGEN instead.
Read only when `rgen packs list` shows this pack as licensed.

Use for people, addresses, phones and national/tax IDs from Chile, Argentina, Mexico, Brazil,
Colombia, Peru and Uruguay. IDs have valid check digits (validated with python-stdnum) but are
random: a value can collide with a real person's, so never present one as real.

## Chains (put each driver in its own column, then pass the column)

| Driver column | Dependent providers |
|---|---|
| country (`latam_country`, or a literal like `'CL'`) | `latam_place(country)`, `latam_given_name(country, sex)`, `latam_surname(country)`, `latam_second_surname(country)`, `latam_national_id(country)`, `latam_tax_id(country)`, `latam_bank(country)`, `latam_company(country)`, `latam_plate(country)`, `latam_street_address(country)`, `latam_currency(country)` |
| place (`latam_place(country)`) | `latam_city(place)`, `latam_region(place)`, `latam_region_code(place)` (ISO 3166-2), `latam_subregion(place)`, `latam_postal_code(place)`, `latam_mobile(place)`, `latam_landline(place)`, `latam_lat(place)`, `latam_lon(place)` |
| sex (`latam_sex`: F/M) | `latam_given_name(country, sex)`, `latam_curp(...)`, `latam_cuit('person', sex)` |
| given, surnames, birthdate (`latam_birthdate`) | `latam_full_name(given, s1, s2)`, `latam_email(given, s1, country)`, `latam_curp(given, s1, s2, birthdate, sex, place)`, `latam_rfc(given, s1, s2, birthdate)` |

Country-specific IDs: `latam_rut('person'|'company')`, `latam_cuit`, `latam_dni_ar`, `latam_cpf`,
`latam_cnpj`, `latam_cedula_co`, `latam_nit`, `latam_dni_pe`, `latam_ruc_pe`, `latam_ci_uy`,
`latam_rut_uy`, `latam_rfc_company`. Chile: `latam_cl_afp` → `latam_cl_afp_rate(afp)`, `latam_cl_health`.

A single-country table with a literal country column and a CURP that matches the person:

```toml
[[tables]]
name = "clientes"
rows = 500

  [tables.columns]
  pais     = { derived = "'MX'" }
  place_id = { derived = "rand_latam_place(pais)" }
  sexo     = { provider = "latam_sex" }
  nombre   = { derived = "rand_latam_given_name(pais, sexo)" }
  paterno  = { derived = "rand_latam_surname(pais)" }
  materno  = { derived = "rand_latam_surname(pais)" }
  nacimiento = { provider = "latam_birthdate" }
  curp     = { derived = "rand_latam_curp(nombre, paterno, materno, nacimiento, sexo, place_id)" }
  rfc      = { derived = "rand_latam_rfc(nombre, paterno, materno, nacimiento)" }
  estado   = { derived = "rand_latam_region(place_id)" }
  cp       = { derived = "rand_latam_postal_code(place_id)" }

[output]
format = "duckdb"
```

Templates cover the common cases: `latam/customers` (all 7 countries), `latam/customers-mx`,
`latam/customers-br`, `latam/invoices-cl` (DTE with IVA), `latam/payroll-cl`.

## Pitfalls

- Nesting a provider inside another (`latam_city(latam_place('CL'))`) re-draws the inner value at
  each reference, so city, region and phone stop matching. Keep `place_id` as its own column.
- `latam_national_id('MX')` returns a valid CURP for a random person. When the row has a name and
  birth date, use `latam_curp(...)` so they match.
- Postal codes match the region for BR, MX, AR, CO and PE; CL and UY (outside Montevideo) are
  correctly formatted only.
- Chilean AFP commissions are approximate 2024-2025 values; payroll does not compute income tax.

## All providers

Use in `-p` without the `rand_` prefix; in TOML `derived` expressions with it.

- `latam_bank(cc)`: bank of a country weighted by customer base — dependent: latam_bank(country)
- `latam_birthdate(min_age,max_age)`: birth date for an adult, ages 18-80 by default
- `latam_cedula_co()`: Colombian cédula de ciudadanía (8 or 10 digits)
- `latam_ci_uy()`: Uruguayan cédula de identidad with valid check digit, formatted 1.234.567-8
- `latam_city(pid)`: city, town or comuna of a place — dependent: latam_city(place_id)
- `latam_cl_afp()`: Chilean pension fund (AFP) weighted by affiliates
- `latam_cl_afp_rate(fund)`: employee pension deduction % (10% + AFP commission, approximate) — dependent: latam_cl_afp_rate(afp)
- `latam_cl_health()`: Chilean health insurer: Fonasa (about 78%) or an Isapre
- `latam_cnpj()`: Brazilian CNPJ (head office /0001) with valid check digits, formatted 12.345.678/0001-95
- `latam_company(cc)`: fictional company name with the country's legal form (SpA, S.A. de C.V., Ltda., S.A.S., S.A.C.) — dependent: latam_company(country)
- `latam_country()`: country code CL, AR, MX, BR, CO, PE or UY, weighted by population
- `latam_country_name(cc)`: local country name (Brasil, México, Perú, ...) — dependent: latam_country_name(country)
- `latam_country_of(pid)`: country code of a place — dependent: latam_country_of(place_id)
- `latam_cpf()`: Brazilian CPF with valid check digits, formatted 123.456.789-09
- `latam_cuit(kind,sex)`: Argentine CUIT/CUIL with valid check digit, 20-12345678-3; kind person (sex F/M) or company
- `latam_curp(given,surname1,surname2,birthdate,sex,pid)`: Mexican CURP derived from name, birth date, sex F/M and the place's state, valid check digit — dependent: latam_curp(given, surname1, surname2, birthdate, sex, place_id)
- `latam_currency(cc)`: ISO 4217 currency of a country — dependent: latam_currency(country)
- `latam_dni_ar()`: Argentine DNI, formatted 12.345.678
- `latam_dni_pe()`: Peruvian DNI (8 digits)
- `latam_email(given,surname,cc)`: email from a person's name with the country's common providers — dependent: latam_email(given, surname, country)
- `latam_full_name(given,surname1,surname2)`: full name from given name and one or two surnames — dependent: latam_full_name(given, surname1, surname2)
- `latam_given_name(cc,sex)`: common given name for a country and sex F/M, frequency-weighted — dependent: latam_given_name(country, sex)
- `latam_landline(pid)`: landline number with the area code of the place's region — dependent: latam_landline(place_id)
- `latam_lat(pid)`: latitude near a place — dependent: latam_lat(place_id)
- `latam_lon(pid)`: longitude near a place — dependent: latam_lon(place_id)
- `latam_mobile(pid)`: mobile number in international format with the place's area code where used (AR, BR, MX) — dependent: latam_mobile(place_id)
- `latam_national_id(cc)`: personal ID of a country: RUT, DNI, CURP, CPF, cédula, DNI, CI (use latam_curp for a CURP that matches a person) — dependent: latam_national_id(country)
- `latam_nit()`: Colombian company NIT with valid verification digit, formatted 900.123.456-7
- `latam_phone_digits(phone)`: E.164 form of a formatted phone number (+5622345678) — dependent: latam_phone_digits(phone)
- `latam_place(cc)`: population-weighted place id in a country; drives region, city, postal code and phone — dependent: latam_place(country)
- `latam_plate(cc)`: vehicle plate in the country's current formats (CL BCDF12, BR Mercosur ABC1D23, ...) — dependent: latam_plate(country)
- `latam_postal_code(pid)`: postal code consistent with the place's region (BR CEP, MX CP, AR CPA, CO, PE; format-only for CL and UY outside Montevideo) — dependent: latam_postal_code(place_id)
- `latam_region(pid)`: first-level region of a place (región, estado, provincia, departamento, UF) — dependent: latam_region(place_id)
- `latam_region_code(pid)`: ISO 3166-2 code of a place's region, e.g. CL-RM, BR-SP, MX-JAL — dependent: latam_region_code(place_id)
- `latam_rfc(given,surname1,surname2,birthdate)`: Mexican RFC for a person (13 chars) from name and birth date, valid check digit — dependent: latam_rfc(given, surname1, surname2, birthdate)
- `latam_rfc_company()`: Mexican RFC for a company (12 chars), valid check digit
- `latam_ruc_pe(kind)`: Peruvian RUC (11 digits, 20... companies, 10+DNI persons) with valid check digit
- `latam_rut(kind)`: Chilean RUT with valid check digit, formatted 12.345.678-5; kind person or company
- `latam_rut_uy()`: Uruguayan company RUT (12 digits) with valid check digit
- `latam_second_surname(cc)`: maternal surname (always in Spanish-speaking countries, half the time in BR) — dependent: latam_second_surname(country)
- `latam_sex()`: sex F or M (51/49)
- `latam_street_address(cc)`: street and number written the local way (Calle 45 # 12-34 in CO, Rua ..., 120 in BR) — dependent: latam_street_address(country)
- `latam_subregion(pid)`: second-level unit of a place (provincia, municipio, partido) — dependent: latam_subregion(place_id)
- `latam_surname(cc)`: common surname for a country, frequency-weighted — dependent: latam_surname(country)
- `latam_tax_id(cc)`: company tax ID of a country: RUT, CUIT, RFC, CNPJ, NIT, RUC, RUT — dependent: latam_tax_id(country)

## Templates

Print one with `rgen templates <pack>/<name> > file.toml`, edit, then `rgen run --config file.toml out.duckdb`.

- `latam/customers`: Customers across 7 Latin American countries: local names, national ID, city, region, postal code, phone, email, bank
- `latam/customers-br`: Brazilian customers with CPF, CEP by state, DDD phone and city
- `latam/customers-mx`: Mexican customers with CURP and RFC derived from name and birth date, state, CP and phone
- `latam/invoices-cl`: Chilean companies and electronic tax documents (DTE): facturas, boletas, notas de crédito with IVA 19%
- `latam/payroll-cl`: Chilean payroll: RUT, AFP and health insurer, gross pay, pension (10% + commission), health (7%) and unemployment insurance (0.6%) deductions
