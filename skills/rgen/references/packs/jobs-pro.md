# Data pack: jobs-pro (Jobs Pro 1.0.0)

Generated by rgen-cli/site-packs.sh from the pack; edit lookup_data/packs/jobs-pro/skill.md in cuiqGEN instead.
Read only when `rgen packs list` shows this pack as licensed.

Use for large volumes of varied job titles when coherence with a department, occupation or
salary does not matter. For titles that must match a department, skills or pay, prefer the `hr`
pack if it is licensed.

## Recipes

```bash
rgen run -n 1000 -p "uuid;job_title_pro as title;job_title_composed as composed_title" titles.csv
```

## All providers

Use in `-p` without the `rand_` prefix; in TOML `derived` expressions with it.

- `job_title_composed()`: composed job title: modifier + base role
- `job_title_pro()`: job title from 10k+ real-world titles
